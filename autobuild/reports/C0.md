## Found and fixed along the way

- The first version of the branded-id helper silently produced plain `string` types (calling
  `.describe()` after `.brand()` in a generic helper drops the brand). ESLint flagged a
  "needless" cast, which exposed it. Fixed, and `src/ids.test.ts` now fails `pnpm typecheck`
  if the brands are ever lost.
- The logger's redaction hid token counts (`inputTokens`) because the name contains "token",
  and reported shared objects as circular. Fixed, with tests.
