## What was built

- **`@repo/channel-meta` (extended, not forked):** `GraphApiError.subcode`; `classifyGraphError`
  reads subcodes (window closed 10/2534022 and 10/2018278; another app controls the thread
  10/2018300, 100/2534037; person unavailable 551, 200/1545041, 10/2018108); downloads with
  no token for signed CDN links; `uploadMessageAttachment`; `exchangeForLongLivedToken`.
- **Contracts (additive, `contracts/channel.ts`):** `human_agent_replied.attribution`
  (`external` | `unverified`), a `delivery_watermark` signal, `SendTarget.standardWindowOpen`.
- **`@repo/channel-messenger-instagram`:** two stateless adapters sending through the Page
  (`POST /{page-id}/messages`, Page token). Parses text, quick-reply taps, postbacks, image /
  video / audio / file attachments (url sources), the like sticker, shares and referrals as
  metadata, story replies and mentions (`story_reply`), reactions, inline replies,
  standby-marked events, deliveries (ids and watermarks), reads (watermark / message id),
  policy enforcement; skips deleted messages, admin notices, self-tests. Echoes: ours dropped
  (our app id or our metadata marker), another app's id → `human_agent_replied` (external),
  no app id (Instagram) → unverified. Sends `RESPONSE`, or `MESSAGE_TAG` + `HUMAN_AGENT` for a
  person's reply after the standard window; quick replies (≤13 × 20) or written under the
  text; media uploaded then sent by attachment id, caption as a following text; `mark_seen`,
  typing; Instagram text kept within 1,000 bytes. Fixtures and a fake Graph API in `/testing`;
  a live check script.
- **`/server`:** `createMetaPagesService` (Facebook Login completion with long-lived token
  exchange, proof of control through `/me/accounts`, messaging-task check, Page subscription,
  Messenger and Instagram connections with the Page token encrypted, `choose_page` when the
  login shared several Pages, another business's Page/account refused, list, disconnect with
  unsubscribe once unused), `createMetaPagesEventHandler` (policy block / unblock / warning on
  the named connection only, never older than `connected_at`), `metaChannelGuard` (story
  replies per `channels.instagram.story_replies`, Meta's standby channel).
- **Pipeline:** an echo is matched against our own sends (stored ids, `message_parts`, send
  journals, then for unverified echoes the words of a recent outbound message) before it
  becomes a person's reply and a takeover (C9's provider-inbox path); `delivery_watermark`
  applied through `applyDeliveryStatus`; the send step passes `standardWindowOpen` (with the
  one-minute margin); new `PipelineDeps.channelGuards`.
- **apps/web:** both adapters, both event handlers and the guard registered when
  `META_APP_SECRET` and `META_WEBHOOK_VERIFY_TOKEN` are set (echo attribution uses
  `META_APP_ID`); `POST /api/oauth/meta/facebook` (agency staff, same-origin JSON via
  `isSameOriginRequest`, 401/403/404/409/415/400/502/503 paths); `getMetaPages()` for C16.
- **Docs:** ARCHITECTURE §2 "As built (C10)", BUILD_PLAN "Delivered" for C10, DECISIONS
