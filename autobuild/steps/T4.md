# T4 · Acceptance: KPI reading and build report

## Outcome

The KPI is measured by a script, and the build report says what was built and verified.

## Read

- autobuild/plan.json, the `kpis` entry
- test/slugify.test.js

## Owns

- scripts/kpi.mjs, autobuild/kpi.json, docs/BUILD_REPORT.md, docs/HUMAN_TODO.md

## Done when

- `npm run verify` exits 0
- `node scripts/kpi.mjs` runs `node --test test/slugify.test.js`, counts the passing and failing
  tests, and writes `autobuild/kpi.json` as
  `{ "K1": { "value": <share passing, 0 to 1>, "target": ">= 1", "pass": <true|false> } }`.
  It exits 0 when it could measure, whatever the reading
- `autobuild/kpi.json` shows K1 with `"pass": true`
- docs/BUILD_REPORT.md states in under twenty lines what was built, the K1 reading and how it
  was measured; docs/HUMAN_TODO.md exists and says there is nothing to do

## Out of scope

- Any change to src/ or test/.
