# C0 plan: architecture and repo

Goal: fix the architecture and the contracts between chunks, and leave a monorepo in which
`pnpm install` and `pnpm verify` pass, so every later chunk starts from compiled interfaces
instead of prose.

## Steps

1. Decide the architecture: components, inbound-to-reply data flow, tenancy and security
   model, job design, folder layout and package dependency layers.
2. Scaffold the monorepo: pnpm workspace with a version catalog, Turborepo, strict TypeScript,
   one root ESLint flat config (type-aware), Prettier, Vitest.
3. `packages/core`: the cross-chunk contracts as real TypeScript and Zod (channel adapter and
   normalized message, conversation engine and its ports, settings resolver, integration
   connector, lead events and the job event catalogue), plus ids, errors, logger, trace context
   and the environment-variable spec.
4. One placeholder package per later chunk, with its allowed workspace dependencies enforced
   by a boundary check that runs in `pnpm verify`.
5. `apps/web`: a minimal Next.js App Router app (layout, home page, `/api/health`) with
   Tailwind wired, ready for C3, C8 and C15.
6. `.env.example` generated from the env spec, with a test that fails when they drift.
7. GitHub Actions workflow running `pnpm verify` on pull requests.
8. Docs: ARCHITECTURE.md, BUILD_PLAN.md, HUMAN_TODO.md, DECISIONS.md, CLAUDE.md (< 80 lines).
9. Prove every "Done when" item and write `autobuild/reports/C0.md`.

## Choices made up front

- Internal packages export TypeScript source (no build step); Next transpiles them.
- TypeScript 6.0.x, because typescript-eslint does not support TypeScript 7 yet.
- Contracts live in `@repo/core`; implementations are injected at two composition roots
  (`packages/pipeline` for domain wiring, `apps/web` for infrastructure wiring).
- Claude API facts (always-on thinking, no forced tool choice, refusal handling, cache
  ordering) are taken from the current API reference and written into the engine contract so
  C4, C6 and C7 do not rediscover them.
