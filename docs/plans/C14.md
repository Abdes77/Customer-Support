# C14 plan: CRM and webhook connectors

Owner paths: `packages/integrations`, `docs/INTEGRATIONS.md`, the CRM OAuth and connect routes in
`apps/web` (`/api/oauth/crm/*`, `/api/integrations/crm/*`), `apps/web/src/server/integrations`;
contract owner of `packages/core/src/contracts/integration.ts`. Shared files touched by the
rules of BUILD_PLAN: a migration and schema in `packages/db` (+ isolation matrix, an agency
secret store), the event catalogue, the env spec, the server composition.

## Shape

- **Contract** (`@repo/core`, additive): `LeadSyncPayload` gains derived name parts and ZIP,
  the latest booking and an optional transcript; `ConnectorContext` gains `options` (lead
  source, tags, report and transcript switches, duplicate policy); `updateLead` gets the stored
  `ExternalRecord` (with connector state such as a CRM's contact id); optional
  `credentialsExpireSoon`. Connectors are built by factories that take the deployment's app
  config (OAuth apps, ServiceTitan app key), so credentials hold only the tenant's secrets.
- **Field mapping** (pure): dot paths into the payload, transforms, a catalogue of sources for
  C16's editor; a CRM's setting replaces its default mapping when it has entries. Connectors
  send exactly the mapped fields (plus the notes the settings switch on).
- **Connectors** (stateless, injected `fetch`, every vendor answer checked with Zod, errors
  mapped to `ConnectorError`): HubSpot (OAuth or private-app token; contacts upsert by email,
  search by phone, a note with the report), GoHighLevel (OAuth or private integration token;
  contact upsert, note, optional opportunity), Jobber (OAuth; GraphQL with variables only:
  client, request, note), Housecall Pro (API key; customer search/create, lead), ServiceTitan
  (client credentials + app key; booking through a booking provider, `externalId` = our key).
- **Generic webhook**: canonical JSON body, `X-HSRB-Signature: t=<unix>,v1=<hmac-sha256(secret,
  "t.body")>`, per-target secret, HTTPS only, the crawler's address rules (copied: domain
  packages do not import each other), one DNS resolution and the socket pinned to the checked
  address, redirects not followed, 10 s limit, response body discarded.
- **Data** (migration 0013): `integration_records` (one row per connection and lead: the
  external id and state, the hash of the last payload; its row lock serializes pushes),
  `integration_events` gains `target`, `next_attempt_at`, `locked_until`, `completed_at`
  (it is the delivery journal), a unique webhook-target index on `integration_connections`,
  `agency_secrets` (agency-wide webhook signing secrets, system only).
- **Jobs**: `integrations-lead-{qualified,meeting-requested,handoff,disqualified,emergency}`
  and `integrations-booking-changed` plan one delivery row per target (idempotency key = event
  id + connection) and emit `integrations.delivery_requested`; `integrations-deliver` makes
  the attempts with backoff (1, 5, 15, 60, 240 minutes; Retry-After honoured), each attempt
  checks the journal first; `integrations-sweep` (every five minutes) re-emits lost ones.
- **Services for C16** (`createIntegrationService`): availability, connector catalogue and
  mapping sources, OAuth start/state/complete, connect with key, list, config, test,
  disconnect, event log, retry, mapping preview, webhook targets with status, reveal and rotate
  of signing secrets (business and agency), test webhook, URL check.
- **apps/web**: `getIntegrations()`, `POST /api/oauth/crm/{hubspot|gohighlevel|jobber}` +
  callback, `POST /api/integrations/crm/{provider}` (API-key connect), jobs registered.

## Tests

Unit: mapping and transforms, signing and verification, address rules, the safe poster
(injected DNS and transport). Contract tests per connector against recorded-style fixtures
(create, existing contact, update, auth/rate/validation errors, refresh, customer text sent as
data). Webhook against a local HTTP receiver that verifies the signature. Database tests: event
→ deliveries per settings, delivery once on re-runs, a failing target does not block others,
auth failure marks the connection, retry with backoff, booking update, sweeper, connection
service, OAuth state, secret reveal and rotation, no tokens in rows or logs.
